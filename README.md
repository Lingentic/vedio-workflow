# 电商视频工作台

输入本地商品视频，结合固定主播片段、模板文案与 AI 配音，制作一条完整的电商短视频。

当前可运行版本位于 **[demo/](demo/README.md)**，采用独立原型的五模块 UI。素材中心、文案／配音、AI 选片、本地成片合成和生成记录接真实服务；商品获取接本机采集服务，发布中心保留原型演示。

## 当前功能

| 模块 | 功能 |
| --- | --- |
| 素材库 | 按商品管理资料及本地视频／图片；搜索商品或当前目录文件；原视频可切分并命名，支持预览、删除和失败文件重试。 |
| 视频制作 | 架构模版 → 文案 → 视频生成；两个固定模板，确认文案后自动配音；AI 一次匹配商品视频空位，可手动调整、设置主播下半屏图片及字幕／配乐，再合成本地 MP4。 |
| 生成记录 | 仅展示已提交视频生成的任务和执行进度；按任务／商品关键词、状态、首次提交日期筛选；继续未完成任务、查看成片及导出副本。 |
| 商品获取 | 同页接本机 Python 服务与 Chrome 扩展，支持采集和导入素材中心。 |
| 发布中心 | 保留原型界面和独立演示数据，未连接发布服务。 |

新选片按实际配音时间编译为时间轴，不接回旧连续随机队列；固定主播／口播画面保留。仅改字幕或配乐时沿用已保存画面及配音，无需再调用模型。

## 快速启动

当前主要在 Windows 上验证。需要 Node.js 24，以及已加入 PATH 的 FFmpeg、FFprobe；FFmpeg 需支持 H.264 编码与 ASS 字幕。

在仓库根目录执行：

```powershell
cd demo
node server.ts
```

打开 [http://127.0.0.1:4186/](http://127.0.0.1:4186/)。Windows 也可双击 `demo/启动Demo.cmd`。没有 npm 生产依赖，无需 `npm install`。

文案／配音／AI 选片需要阿里云调用配置，原片预览需要本地媒体，详见 [Demo 使用说明](demo/README.md)。仓库包含三首 [CC0 默认配乐](demo/data/bgm/README.md)，不包含密钥、用户媒体或成片；随附的原型示意图片仅供演示。

## 上游素材采集

`ecom-video-collect/` 是独立的上游采集模块：Chrome 扩展读取快分销商品详情与图集，本地 Python 服务检索快手／抖音视频并入池，随后一键经 `/api/products` 上游接口把商品与已下载视频导入工作台素材库。运行方式、扩展安装与凭证配置见 [ecom-video-collect/README.md](ecom-video-collect/README.md)。它不是 demo 启动流程的一部分，不采集时无需启动。

## 一次制作流程

1. 在素材库选择商品，准备好商品视频与模板对应的固定主播素材。
2. 在视频制作选择架构模板，进入文案页选择商品，建立任务；价格、规格只读，最终口播变量可修改。
3. AI 补全文案或手动修改待填部分；点击“确认文案并生成配音”，服务端自动生成连续口播和字幕时间。
4. 在视频生成页点击 AI 匹配素材，检查／调整各段选片和主播下半屏共用商品图；字幕与配乐在段落预览上方独立设置。
5. 点击生成视频，后台用 FFmpeg 合成；失败或停止后可手动重试本地合成。成功后可预览、返回修改、确认完成，或将副本导出到自选目录。

默认数据保存在运行电脑实际“视频”文件夹下的 `电商视频工作台Demo`，支持在界面中更换目录。制作页恢复最近一份草稿，首次受理视频合成后才进入生成记录；停止、失败、重试更新同一记录。服务重启后恢复已保存结果，不自动重发付费请求。

## 技术与文档

- TypeScript + Node.js 24 原生 HTTP 服务、SQLite，浏览器端 HTML/CSS/TypeScript。
- FFmpeg 完成本地画面拼接、裁剪、上下分屏、配乐与字幕合成。
- 模型使用阿里云渠道：文案 `qwen3.7-plus`、配音 `qwen-audio-3.1-tts-plus`、选片 `deepseek-v4.1-flash`。配置可读不等于账户有调用权益。

从 [AGENTS.md](AGENTS.md) 进入，按 [仓库导航](AGENT_WIKI.md) 选择当前任务所需的产品、架构、数据或验证专题；无需通读历史资料。
