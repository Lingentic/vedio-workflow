# 电商视频工作台

输入本地商品视频，结合固定主播片段、模板文案与 AI 配音，制作一条完整的电商短视频。

当前可运行版本位于 **[demo/](demo/README.md)**，采用独立原型的五模块 UI。素材中心、文案／配音和生成记录接真实本地服务；商品获取、发布中心保留原型演示。**选材正待重构，当前页面不开放视频合成，也不调用旧连续队列。**

## 当前功能

| 模块 | 功能 |
| --- | --- |
| 素材库 | 保存商品 ID、名称、价格、规格、卖点及本地视频；商品下拉框内按名称或 ID 搜索；区分已处理与未处理素材，支持预览、删除和失败文件重试。 |
| 视频制作 | 架构模版 → 文案 → 视频生成；两个固定模板，全文编辑待填内容，确认文案后自动配音与试听。逐段选材仅演示，合成按钮暂禁用。 |
| 生成记录 | 保存草稿和执行进度；按任务／商品关键词、状态、创建日期筛选；继续未完成任务、查看成片及导出副本。 |
| 商品获取／发布中心 | 保留原型界面和独立演示数据，未连接真实抓取、素材入库或发布服务。 |

此前后端合成能力保留，既有成片可继续查看和导出；这些接口的存在不代表已接入新选材界面。

## 快速启动

当前主要在 Windows 上验证。需要 Node.js 24，以及已加入 PATH 的 FFmpeg、FFprobe；FFmpeg 需支持 H.264 编码与 ASS 字幕。

在仓库根目录执行：

```powershell
cd demo
node server.ts
```

打开 [http://127.0.0.1:4186/](http://127.0.0.1:4186/)。Windows 也可双击 `demo/启动Demo.cmd`。没有 npm 生产依赖，无需 `npm install`。

文案／配音需要阿里云调用配置，原片预览需要本地媒体，详见 [Demo 使用说明](demo/README.md)。仓库不包含密钥、用户视频、BGM 或成片；随附的原型示意图片仅供演示。

## 一次制作流程

1. 在素材库选择商品，准备好商品视频与模板对应的固定主播素材。
2. 在视频制作选择架构模板，进入文案页选择商品，建立任务；价格、规格只读，最终口播变量可修改。
3. AI 补全文案或手动修改待填部分；点击“确认文案并生成配音”，服务端自动生成连续口播和字幕时间。
4. 在视频生成页查看原片、试听配音；逐段选材暂为界面演示，真实编排与合成后续接入。
5. 在生成记录继续任务，或查看、导出此前已经保存的成片。

默认数据保存在运行电脑实际“视频”文件夹下的 `电商视频工作台Demo`，支持在界面中更换目录。切换页面可保留制作进度；服务重启后恢复已保存的任务，不自动重发付费请求。

## 技术与文档

- TypeScript + Node.js 24 原生 HTTP 服务、SQLite，浏览器端 HTML/CSS/TypeScript。
- FFmpeg 完成本地画面拼接、裁剪、上下分屏、配乐与字幕合成。
- 文案与配音使用阿里云官方渠道；当前配置为 `qwen3.7-plus`、`qwen-audio-3.1-tts-plus`。

## Agent 开发入口

从 [AGENTS.md](AGENTS.md) 进入，按 [仓库导航](AGENT_WIKI.md) 选择当前任务所需的产品、架构、数据或验证专题；无需通读历史资料。

文档改动可运行 `node scripts/check-harness.mjs`；环境或启动问题再运行 `node scripts/doctor.mjs`。不要求每次两项都跑。类型检查、隔离运行和按改动选择测试见 [开发与验证](docs/harness/DEVELOPMENT.md)。
