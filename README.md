# 电商视频工作台

输入本地商品视频，结合固定主播片段、模板文案与 AI 配音，制作一条完整的电商短视频。

当前可运行版本位于 **[demo/](demo/README.md)**，包括素材库、视频制作、生成记录三个模块。它是独立的本地网页与 TypeScript 服务，视频由本机 FFmpeg 合成。

## 当前功能

| 模块 | 功能 |
| --- | --- |
| 素材库 | 保存商品 ID、名称、价格、规格、卖点及本地视频；商品下拉框内按名称或 ID 搜索；区分已处理与未处理素材，支持预览、删除和失败文件重试。 |
| 视频制作 | 两个固定模板；补全文案、确认文案、连续口播配音、自动组装画面、整条素材拖动排序、字幕与 BGM 设置、成片预览。 |
| 生成记录 | 保存草稿和执行进度；按任务／商品关键词、状态、创建日期筛选；继续未完成任务、查看成片及导出副本。 |

成片固定为 **9:16、1080×1920、30 FPS、MP4**。商品素材静音；主播原片保留原声，上方主播、下方商品，接缝渐变；全片统一使用可开关的黄色黑描边字幕。

## 快速启动

当前主要在 Windows 上验证。需要 Node.js 24，以及已加入 PATH 的 FFmpeg、FFprobe；FFmpeg 需支持 H.264 编码与 ASS 字幕。

在仓库根目录执行：

```powershell
cd demo
node server.ts
```

打开 [http://127.0.0.1:4186/](http://127.0.0.1:4186/)。Windows 也可双击 `demo/启动Demo.cmd`。没有 npm 生产依赖，无需 `npm install`。

完整流程还需要准备阿里云调用配置和本地媒体，详见 [Demo 使用说明](demo/README.md)。仓库不包含密钥、商品／主播视频、BGM 或已经生成的成片。

## 一次制作流程

1. 在素材库选择商品，准备好商品视频与模板对应的固定主播素材。
2. 开始新制作，选择商品和模板；参考价格、规格填写模板变量，生成并确认补全文案。
3. 生成、试听并确认连续口播配音；字幕时间使用配音接口返回的时间记录。
4. 自动组装画面，需要时添加、移除或拖动完整片段，再保存方案；手动方案时长不足时不能合成。
5. 选择字幕和 BGM，生成预览。不满意可以返回调整；只改字幕或 BGM 时沿用当前画面顺序。
6. 点击“确认完成”后参数只读，成片保存在本机数据目录；导出到其他文件夹是可选操作。

默认数据保存在运行电脑实际“视频”文件夹下的 `电商视频工作台Demo`，支持在界面中更换目录。切换页面可保留制作进度；服务重启后恢复已保存的任务，不自动重发付费请求。

## 技术与文档

- TypeScript + Node.js 24 原生 HTTP 服务、SQLite，浏览器端 HTML/CSS/TypeScript。
- FFmpeg 完成本地画面拼接、裁剪、上下分屏、配乐与字幕合成。
- 文案与配音使用阿里云官方渠道；当前配置为 `qwen3.7-plus`、`qwen-audio-3.1-tts-plus`。
