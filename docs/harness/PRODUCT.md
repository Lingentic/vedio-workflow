# 当前产品契约

这是当前 Demo 所采用的已确认行为快照，供新 Agent 在没有历史对话和本机资料时使用。用户后续决定优先。以下规则不是“所有条目均已自动化验证”的声明；实际代码、验证证据与待补实现分别见 [架构](ARCHITECTURE.md)、[数据](DATA_AND_LIFECYCLE.md)、[开发](DEVELOPMENT.md)。

## 范围与名词

| 编号 | 已确认规则 |
| --- | --- |
| P01 | 界面采用原型的商品获取、视频制作、生成记录、发布中心、素材中心五模块。真实后端接商品获取、素材中心、文案／配音、生成记录；发布为明确标记的原型演示。逐空位AI选片及本地合成已接入，新 UI 不使用旧连续随机队列。使用两个固定模板，商品采集沿用主线的独立本机服务与扩展；不新增发布或通用模板编辑能力。 |
| P02 | 上游输入商品 ID、名称、价格、规格、卖点和下载好的本地视频；制作只从素材库读取。商品按 ID 关联素材；原视频待用户选择后切分并生成短名称、画面描述。 |
| P03 | `host_clip` 是固定主播原片，保留原声；`fixed_narration` 是固定 AI 口播及模板变量；`generated_narration` 是待生成／可手改文字。颜色只便于人类讨论，模型协议使用显式节点类型和 ID。 |
| P04 | 生成视频提交前仅保存制作草稿，不出现在生成记录；首次受理视频合成后显示一条生成记录，之后成功、失败、停止、重试、返工均更新同一条记录。模板／商品快照不自动跟随公共资料变化。 |

## 商品获取

- 沿用当前五模块工作台及采集详情布局，只增加入库状态筛选、标记和单条操作；制作、素材中心、生成记录与发布页面沿用当前版本，不切回旧 UI。
- 平台搜索需要本机配置与对应登录态，失败明确反馈，不用演示数据冒充成功。采集页可缓存账户草稿，提交后真实商品／素材仍以服务端为准。
- 录入弹窗按 pm 原型显示基本信息与联网爬取两列；表单只含快手商品 ID、商品名称、价格、佣金比例、所属平台、规格、类目、负面词汇，不增加商品卖点字段。
- 采集返回的主图和详情图一律进入图片候选，不自动归档；视频搜索同样先进入候选区。勾选只进入临时「已勾选」清单，取消勾选或移除同步更新计数。确认后仅将已勾选的素材归档并提交工作台，未勾选图片（含主图）不入库。重新爬取保留已勾选清单。

- 正式入口默认在线播放，无需额外 URL 参数。未入库的候选视频在线播放，图片通过代理预览；预览不保存完整媒体。勾选并确认入库才下载保存原视频。在线候选支持按时间前后拖动，定位时从目标位置重新推流，可能短暂缓冲；已入库及已有本地素材仍使用可拖动的本地预览。

- 商品详情的视频和图片各提供“全部／已归入素材中心／未归入素材中心”筛选，按工作台实际入库成功标记分类；未归入卡片可单独归入，同步失败保留失败原因和重试入口，不归入其他未选素材。采集回来的图片也保留在未归入列表。
- 新的爬取面板默认同时选中快手和抖音，用户可自行取消渠道。商品尚无候选时为“待爬取”（pending），已有候选或已采集图集但没有成功入库素材时为“待入库”（awaitingImport）；成功入库后为“素材就绪”，仅爬到候选或同步失败均不能标就绪。

## 素材库

- UI 以 2026-10-29 最新原型为基准：素材中心采用 IP／产品分类、左侧目录及右侧素材网格；制作采用模板预览、全文文案、分组段落和右侧预览；生成记录采用筛选台账及折叠详情。组件沿用原型样式，实际数据与接口仍由 Demo 提供。
- 产品目录搜索按名称或 ID 查整个商品库，选择目录后显示该商品素材，保留全部产品入口；右侧另提供当前目录文件搜索，两种搜索范围明确区分。
- 素材文件按全部／视频切片／原始视频／图片／声音筛选，不再叠加已处理／未处理状态筛选。缩略图属于原视频，不算独立图片；图片不进入商品视频选材。当前图片入库边界见开发专题。
- 生成记录支持商品或任务名称、任务 ID、商品 ID、状态及日期筛选；详情分为任务信息、预览成片、视频设置。提交发布相关控件禁用，不把原型演示记录混入真实业务库。
- 价格、规格在制作中只读，帮助用户填写最终变量；AI 文案使用商品卖点，价格字段不作为独立模型参考。最终变量和范例中已有价格时，模型可在上下文允许的范围承接。
- 用户手工处理好的视频直接入库；原始视频进入“原始视频”，按当前商品勾选或全选待处理源视频后显式“切分并命名”。默认阈值 15.2、最短片段 1.9 秒，折叠设置保存到当前库；已建立切分计划的重试沿用原参数。成功命名后子片段进入“视频切片”，可展开画面描述；已完成的托管原视频仍可在“原始视频”回看并标为“已切分”，不重复处理；未完成的内部子片段只作为恢复材料。完整规则见 [素材切分与命名](MATERIAL_PROCESSING.md)。
- 可以预览、删除单个托管商品片段；正在用于合成的输入不允许删除。删除素材不能把成片或文案一起删掉。商品删除不属于当前入口。
- 外部用户原文件保持不动；新切分命名流程保留托管原视频用于来源与恢复。历史已清理源记录仍按原状态保留，不自动修复或重处理。

## 文案与配音

- 制作导航为“架构模版 → 文案 → 视频生成”。选定模板后，在文案页选择商品即保存制作草稿；生成文案、配音或浏览视频生成页均不增加生成记录。切走后返回视频制作默认恢复同一草稿及步骤，刷新后也恢复；制作页只恢复最近使用的一份草稿，不提供已有任务板块或历史草稿列表。已提交视频生成的任务可从生成记录继续。切换商品／模板的确认规则见下方“预览、返工与完成”。
- 固定模板顺序、主播台词、固定口播不由模型改写。AI 一次重新生成所有待填节点；用户也可修改黑色文字及蓝色变量，不能在制作中修改价格、规格参考框。
- 文案页采用原型的完整文本编辑视图，按模板顺序呈现固定内容和待填内容；仅待填内容可就地编辑，最终变量仍有独立输入框。生成期间显示进度，不允许修改固定节点。
- 文案输入包含模板节点、商品卖点、可选范例。提供范例时整体长度接近范例；未提供时当前实现按整体约 190～410 字预算生成，不把该字数当成精确视频秒数。
- 相邻固定口播和生成文案合为连续 AI 口播区间，以主播原片分隔。点击“确认文案并生成配音”后立即呈现“正在配音”的加载状态，仍停留文案步骤并锁定步骤切换；全部音频及时间有效后自动进入视频生成页，不另设手动音频确认步骤。失败时显示原因，可返回文案或手动重试未完成配音；不自动重发。
- 配音请求期间冻结相关编辑。返回后再保存文案修改，需要重新生成受影响的连续区间；其余有效音频复用。只重配不改文案。
- 即使文字不变，重配的时长也可能变化，必须重算句子、节点、后续全片位置、画面覆盖和字幕，不能沿用旧时间。
- 当前阿里云模型及声音参数以 [models.ts](../../demo/lib/models.ts) 和 [voice-config.json](../../demo/data/voice-config.json) 为准；失败、超时、断连不自动提交新的付费请求。

## 画面和声音

**本轮接入边界：**视频生成页保留原型式节点浏览、素材选择和预览 UI。固定口播读取服务端的真实媒体绑定；商品选片保存于服务端 Task.shotSelection。字幕／BGM 设置和生成视频已开放；POST render 将新选片编译为完整时间轴，不调用旧 plan 随机队列。既有成片仍可查看、导出。当前编排及输出规则如下；新成片接入以本轮真实FFmpeg及隔离页面验收为准，不把本地模拟配音称作真实模型质量验收。

- 视频生成选项卡可以在文案／配音前浏览；没有商品时显示去选择商品的入口，有任务时直接显示原型页面，不为浏览而更新服务端阶段或提交付费请求。
- 红色主播原声片段下半屏共用一张商品图片，替代此前逐段选择遮罩视频；首次进入视频生成时优先选当前商品图片，缺图则从可用商品视频截一帧。点击图片或“调整图片”打开独立窗口，查看上下屏及固定渐变，拖动图片、缩放、还原位置，或从当前商品图片／本地文件换图。始终裁满下半屏，不能拖出空白。取消不保存，应用统一更新本任务全部主播原声片段；其他段落不变。该功能已接入实时预览、持久化和新选片合成。
- 固定口播画面按 [已核对清单](../../demo/data/fixed-narration-visuals.json) 绑定具体节点和媒体版本；t1-b1、t1-b2、t1-b3、t2-b1 已指定，t2-b2 未指定。t1-b2 使用用户指定原视频的完整画幅，已按现有该句配音约 2.837 秒实际截取开头 85 帧（30 FPS，约 2.833 秒），绑定“原本和厂商谈好卖[自定义文本]的-口播2.83秒.mp4”；不绑定 11.7 秒全长版，也不使用早先误配的 1.8 秒版本。原视频和旧输出保留，声音仍用 AI 配音。绑定画面不参与随机、手选或移除；固定片段短于口播时余段通过商品视频填充，不延长或重复固定视频。t1-b3 对应“老葛听完瞬间感动哭了”，画面在该节点结尾，前部由商品视频补齐；其余已绑定片段从节点开头播放。片段长于口播时只取所需时长。固定绑定、商品补位与合成都已接入。
- 当前视频生成页按原型将相邻口播节点分组；右侧汇总本段全部素材及未绑定空位，点击素材切换到所属节点的原片预览，保留目录式素材多选和上下半屏遮罩。同一商品文案节点内可指针拖动或 Alt＋左右键排序，不跨节点交换素材；固定口播不可排序／移除，缩略图用紫色边框和锁形 SVG 标识。固定口播读取服务端绑定；商品选片只在用户点击AI匹配后请求，结果保存到服务端；手改按空位校验时长后保存，刷新恢复成功方案，旧localStorage示例选择不再覆盖它。
- 生成按钮位于页头，有效配音和选片／图片齐备、手改已保存且无执行时可用。已有 render 执行可呈现独立进度／失败／停止／完成页，状态来自服务端；不模拟原型的去重阶段或生成成功。完成页可导出副本、返回编辑；“去发布”保持禁用，不创建真实发布任务。发布中心的新设置仍属于独立演示。
- 视频生成页不提供连续口播试听／本地配音导入区域，也不显示原片预览的底部提示框；服务端已生成的配音和时间记录保留。主播原片与原声保持固定。画面总时长显示待编排，生成视频已开放，不显示旧随机队列时间线。
- 以完整可用商品视频为素材单位，先自动组装，再允许整条增删、重复、拖动排序；不提供任意切入点或逐镜头裁剪。手动方案时长不足必须阻止合成，不自动替用户补片。
- AI选片先随机抽约3倍时长候选（不足全取，兼顾至少8条、最多40条），只发送全文、描述、ID和时长；一次返回全部商品空位的素材顺序。每个空位按所选完整素材依次播放，仅末条裁断；出现重复明确提示，不使用旧全片随机队列。
- 固定主播原声区间：上方主播、下方商品，接缝渐变，尽量遮住原字幕；不是字幕擦除。AI 区间可先用对应的通用主播画面，其余由商品画面覆盖。
- 固定主播下半屏使用共用静态商品图，不再消耗商品视频队列；AI 商品画面按已保存的逐空位方案处理，固定蓝色覆盖范围排除在商品视频填充之外。
- 商品原声静音。BGM 是独立可选音轨，默认不使用，可调音量；可按当前音量试听，滑杆即时调整试听音量，切换音乐或离开画面页停止试听。短 BGM 循环，末尾裁断。当前把红色主播原片视为没有需单独处理的背景音乐。
- 内置三首 CC0 配乐（Happy Dance、Bouncing、Earth），随代码携带；启动和切换数据目录时复制入库，同一绑定不重复创建，不改已有任务选项。来源和许可见 [配乐说明](../../demo/data/bgm/README.md)。
- 字幕／配乐是全片设置，在视频生成页右侧“段落预览”上方独立成卡，与预览卡同宽，不嵌入段落预览内容。
- 主播下半屏换图入口同时提供本地上传与“从当前商品素材库选择”；后者打开独立图片选择小窗口，只列当前商品可用图片。选图后回到取景调整，点击应用才统一保存；取消保留旧图。
- 红色台词字幕铺满对应原片；AI 字幕由配音时间记录聚合。统一黄色黑描边，可整片开关，不重新调用识别模型。
- 成片固定 9:16、1080×1920、30 FPS、MP4；非目标画幅等比例裁满中心。主播下半屏可使用用户确认的商品图片；其他视频区间不使用图片／缩略图补画面。

## 预览、返工与完成

真实选片、合成、设置返工与确认完成入口已开放；已完成记录只读查看。任务保存、编辑失效和付费请求保护继续生效。

- 生成、配音、合成和素材处理期间局部更新进度与结果，不重建整个页面；保留滚动、输入焦点、打开的搜索及已有播放器，只有新媒体结果替换播放来源。
- 模板只在“架构模版”页用现有下拉框切换，商品只在“文案”页切换，不再提供单独选择商品／模板的窗口或入口。未提交视频且没有非空待填文案时直接覆盖当前草稿；未提交视频但已有文案（含手动填写）时只提供“取消／确认覆盖”。已提交视频的可编辑任务才提供“取消／覆盖当前任务／保留并新建”，旧任务可从生成记录继续；服务端同样拒绝未提交草稿的保留新建请求。弹窗不重复提供商品／模板选择。取消保留原任务、选择和进度，没有实际变更时不提交切换请求。模板应用后留在架构页，商品应用后留在文案页。
- 旧随机队列仅兼容旧任务；新任务以shotSelection为选片依据，修改字幕／BGM只重新合成输出层，固定素材顺序与配音不变。
- 预览过期进入成片页时说明修改原因，并由用户确认重生成。原重生成入口保留；要换选片时独立点击AI重新匹配，不通过合成请求重随机。
- 用户在站内小窗口确认“当前有效预览为最终成片”后才 `completed=true`、参数只读；取消不改变任务。成功合成或导出均不等于确认完成。导出是可选副本，正式文件保存在数据根目录中。
- “导出副本”先打开站内窗口，默认当前电脑 Videos 目录，可填写路径或浏览选择；复制期间显示等待，失败保留窗口供重试，成功显示完整保存路径。每次生成新文件名，不覆盖已有文件。
- 生成记录只展示 `videoSubmittedAt` 非空的任务；创建时间及日期筛选按首次受理视频生成的时间。无视频提交证据的旧任务数据不删除，但不展示为历史草稿；没有保存的当前定位时只恢复最近一份；已有成片／合成执行证据的旧任务兼容展示，不自动重试或清理。
- 生成记录中普通未完成任务标为“未完成”；状态筛选的“未完成”包含所有尚未确认完成的任务，保留独立的进行中／错误筛选。
- 切走页面可继续本地合成；停止合成后保留已成功步骤。重启恢复已保存进度，不让旧任务永久显示运行中，不自动重发云请求。
- 只有确认完成且成片可靠存在后才后台清理本任务中间文件；清理失败不回退完成状态，也不删除共享素材或其他任务。详细边界见 [数据与生命周期](DATA_AND_LIFECYCLE.md)。

## 已知未完成部分

选材需要按原型的逐段方式重构后再接真实合成；商品获取保留主线采集服务接入，发布不接业务后端。切分基线已确认并接入；真实模型命名质量需单独授权验证，统一“先裁首尾再切分”尚未实现。其他缺口见 [开发说明](DEVELOPMENT.md#已知缺口与证据边界)。
