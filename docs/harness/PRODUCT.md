# 当前产品契约

这是当前 Demo 所采用的已确认行为快照，供新 Agent 在没有历史对话和本机资料时使用。用户后续决定优先。以下规则不是“所有条目均已自动化验证”的声明；实际代码、验证证据与待补实现分别见 [架构](ARCHITECTURE.md)、[数据](DATA_AND_LIFECYCLE.md)、[开发](DEVELOPMENT.md)。

## 范围与名词

| 编号 | 已确认规则 |
| --- | --- |
| P01 | 界面采用原型的商品获取、视频制作、生成记录、发布中心、素材中心五模块。真实后端接商品获取、素材中心、文案／配音、生成记录；发布仍为明确标记的原型演示。选材与合成等待重构，当前新 UI 不接旧连续队列。使用两个固定模板，采集由独立本机服务与扩展执行，不新增发布或通用模板编辑能力。 |
| P02 | 上游输入商品 ID、名称、价格、规格、卖点和下载好的本地视频；制作只从素材库读取。商品按 ID 关联素材，不要求语义类别或 AI 命名。 |
| P03 | `host_clip` 是固定主播原片，保留原声；`fixed_narration` 是固定 AI 口播及模板变量；`generated_narration` 是待生成／可手改文字。颜色只便于人类讨论，模型协议使用显式节点类型和 ID。 |
| P04 | 一个制作任务对应一条生成记录。未完成也有记录；重试、暂停、返工不另建记录。模板／商品快照不自动跟随公共资料变化。 |

## 素材库

- UI 以 2026-10-29 最新原型为基准：素材中心采用 IP／产品分类、左侧目录及右侧素材网格；制作采用模板预览、全文文案、分组段落和右侧预览；生成记录采用筛选台账及折叠详情。组件沿用原型样式，实际数据与接口仍由 Demo 提供。
- 产品目录搜索按名称或 ID 查整个商品库，选择目录后显示该商品素材，保留全部产品入口；右侧另提供当前目录文件搜索，两种搜索范围明确区分。
- 素材文件按全部／视频切片／原始视频／图片／声音筛选，与已处理／未处理状态组合。缩略图属于原视频，不算独立图片；图片不进入商品视频选材。当前图片入库边界见开发专题。
- 生成记录支持商品或任务名称、任务 ID、商品 ID、状态及日期筛选；详情分为任务信息、预览成片、视频设置。提交发布相关控件禁用，不把原型演示记录混入真实业务库。
- 价格、规格在制作中只读，帮助用户填写最终变量；AI 文案使用商品卖点，价格字段不作为独立模型参考。最终变量和范例中已有价格时，模型可在上下文允许的范围承接。
- 用户手工处理好的视频直接入库；原始视频进入本地切分。已处理／未处理与异常分开；失败文件单独重试，不重做成功输出。
- 可以预览、删除单个托管商品片段；正在用于合成的输入不允许删除。删除素材不能把成片或文案一起删掉。商品删除不属于当前入口。
- 外部用户原文件保持不动；“处理成功后清理源视频”指客户端管理的处理源副本。

## 文案与配音

- 制作导航为“架构模版 → 文案 → 视频生成”。选定模板后，在文案页选择商品即建立同一条任务记录；生成记录可以继续任务。模板切换仍遵守文案前直接覆盖、文案后确认新建或覆盖的规则。
- 固定模板顺序、主播台词、固定口播不由模型改写。AI 一次重新生成所有待填节点；用户也可修改黑色文字及蓝色变量，不能在制作中修改价格、规格参考框。
- 文案页采用原型的完整文本编辑视图，按模板顺序呈现固定内容和待填内容；仅待填内容可就地编辑，最终变量仍有独立输入框。生成期间显示进度，不允许修改固定节点。
- 文案输入包含模板节点、商品卖点、可选范例。提供范例时整体长度接近范例；未提供时当前实现按整体约 190～410 字预算生成，不把该字数当成精确视频秒数。
- 相邻固定口播和生成文案合为连续 AI 口播区间，以主播原片分隔。点击“确认文案并生成配音”后自动生成缺失／失效区间，全部音频及时间有效后自动进入视频生成页；不另设手动音频确认步骤。页面呈现生成进度，并在视频生成页提供连续口播试听。
- 配音请求期间冻结相关编辑。返回后再保存文案修改，需要重新生成受影响的连续区间；其余有效音频复用。只重配不改文案。
- 即使文字不变，重配的时长也可能变化，必须重算句子、节点、后续全片位置、画面覆盖和字幕，不能沿用旧时间。
- 当前阿里云模型及声音参数以 [models.ts](../../demo/lib/models.ts) 和 [voice-config.json](../../demo/data/voice-config.json) 为准；失败、超时、断连不自动提交新的付费请求。

## 画面和声音

**本轮接入边界：**视频生成页保留原型式节点浏览、素材选择和预览 UI，但素材选择仅在当前页面演示，不保存为真实方案；字幕／BGM 和生成视频暂不可操作。不得因此调用旧 `plan`／`render` 接口。既有成片仍可查看、导出。以下编排及输出规则是后端保留能力与此前约定，须在选材重构时重新对齐，不能宣称当前页面已经接入。

- 视频生成选项卡可以在文案／配音前浏览；没有商品时显示去选择商品的入口，有任务时直接显示原型页面，不为浏览而更新服务端阶段或提交付费请求。
- 当前视频生成页按原型将相邻口播节点分组，可展开小节点；右侧提供原视频、连续口播试听、目录式素材多选、上下半屏遮罩、素材切换及恢复自动。进入时填入示例选择，重新匹配只变更当前页面，不做语义匹配或真实时长编排。
- 本地导入配音仅创建浏览器临时试听地址，不上传、不替换服务端已有配音／时间记录；可以清除。主播原片与原声保持固定。画面总时长显示待编排，生成视频禁用，不显示旧队列时间线。
- 以完整可用商品视频为素材单位，先自动组装，再允许整条增删、重复、拖动排序；不提供任意切入点或逐镜头裁剪。手动方案时长不足必须阻止合成，不自动替用户补片。
- 自动组装对同商品素材随机排队，全片连续取用，上一段未播完的素材在下一段继续；用完再重复并提示，最后只裁掉多余部分。
- 固定主播原声区间：上方主播、下方商品，接缝渐变，尽量遮住原字幕；不是字幕擦除。AI 区间可先用对应的通用主播画面，其余由商品画面覆盖。
- 固定主播下半屏和 AI 商品全屏共用连续商品队列；播放通用主播画面时暂停商品队列。
- 商品原声静音。BGM 是独立可选音轨，默认不使用，可调音量；可按当前音量试听，滑杆即时调整试听音量，切换音乐或离开画面页停止试听。短 BGM 循环，末尾裁断。当前把红色主播原片视为没有需单独处理的背景音乐。
- 红色台词字幕铺满对应原片；AI 字幕由配音时间记录聚合。统一黄色黑描边，可整片开关，不重新调用识别模型。
- 成片固定 9:16、1080×1920、30 FPS、MP4；非目标画幅等比例裁满中心。视频拼接不使用商品图片／缩略图补画面。

## 预览、返工与完成

以下涉及真实方案／合成／预览返工的入口暂不在新制作 UI 中开放；已完成记录继续只读查看。任务保存、编辑失效和付费请求保护继续生效。

- 生成、配音、合成和素材处理期间局部更新进度与结果，不重建整个页面；保留滚动、输入焦点、打开的搜索及已有播放器，只有新媒体结果替换播放来源。
- 切换窗口先只显示商品、模板两个下拉框；点击“应用”后，没有非空待填文案时直接覆盖当前草稿，已有文案（含手动填写）才通过站内窗口选择新建或覆盖。新建保留原任务，覆盖清空当前进度；返回可保留刚选的商品和模板，关闭不修改任务，没有实际变更时直接关闭，不清空进度。
- 原队列返工能力仍保留在后端；新 UI 的演示选择不提交计划，也不作为已保存进度。后续重接编排时继续遵守“仅改字幕／BGM 不重新选片”的规则。
- 预览过期进入成片页时说明修改原因，并由用户确认重生成。原重生成入口保留；明确选择重新填充时才重随机画面，不重做文案或配音。
- 用户在站内小窗口确认“当前有效预览为最终成片”后才 `completed=true`、参数只读；取消不改变任务。成功合成或导出均不等于确认完成。导出是可选副本，正式文件保存在数据根目录中。
- 生成记录中普通未完成任务标为“未完成”；状态筛选的“未完成”包含所有尚未确认完成的任务，保留独立的进行中／错误筛选。
- 切走页面可继续本地合成；停止合成后保留已成功步骤。重启恢复已保存进度，不让旧任务永久显示运行中，不自动重发云请求。
- 只有确认完成且成片可靠存在后才后台清理本任务中间文件；清理失败不回退完成状态，也不删除共享素材或其他任务。详细边界见 [数据与生命周期](DATA_AND_LIFECYCLE.md)。

## 已知未完成部分

选材需要按原型的逐段方式重构后再接真实合成；商品获取接采集服务，发布暂不接业务后端。镜头切分参数未验收；统一“先裁首尾再切分”尚未实现。其他缺口见 [开发说明](DEVELOPMENT.md#已知缺口与证据边界)。

## 商品获取

沿用商品录入、联网搜索、视频／图片候选及导入素材中心的采集界面；实际结果以服务端入库记录为准。平台搜索需要本机配置与对应登录态，失败明确反馈，不用演示数据冒充成功。采集页可缓存账户草稿，发布功能仍不接入。

- 正式入口默认在线播放，无需额外 URL 参数。未入库的候选视频在线播放，图片通过代理预览；预览不保存完整媒体。勾选并确认入库才下载保存原视频。在线候选支持按时间前后拖动，定位时从目标位置重新推流，可能短暂缓冲；已入库及已有本地素材仍使用可拖动的本地预览。
