# 原型界面来源

本目录保存从 `Lingentic/pm` 独立电商原型提取的样式，以及商品获取、发布中心的演示模块。来源版本为 `9e2d21b4fdae6effcadb6774af87634211f06395`（2026-10-29 11:47），同步日期为 2026-10-29。

- `styles.css`、令牌、品牌、独立窗口及 `ecommerce-video-*.css` 保持原型的页面结构与视觉。上级 `workbench.css` 仅负责实际数据入口、弹窗挂载及浏览器窄窗口适配。
- 商品获取、发布中心保留原型交互，使用独立的浏览器演示数据；不访问 Demo 业务 API，也不执行真实抓取、上传或发布。
- 随附图片及两个图片索引脚本仅用于商品获取／发布的原型演示，不能作为实际商品素材或视频生成输入；商品缩略图的来源记录见 `assets/ecommerce-product-thumbnails/manifest.json`。
- 真实素材、文案、配音、记录接入在上级 `app.ts` 与 `prototype-views.ts`：素材工作台的目录浏览、架构模版、全文文案、分组段落及台账／折叠详情沿用原型结构。选材多选与预览仍只是 UI 演示，未接入原队列或合成。
- 原型本机源目录保持不变。复制的脚本仅将示意图片路径调整到本目录，避免依赖原项目位置。

上游仓库：https://github.com/Lingentic/pm
