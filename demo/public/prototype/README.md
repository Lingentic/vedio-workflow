# 原型界面来源

本目录保存从 `Lingentic/pm` 独立电商原型提取的样式，以及商品获取、发布中心的演示模块。来源版本为 `21704c8a84b5070ce03e1281f7eaf0816324b372`，接入日期为 2026-10-29。

- `styles.css`、令牌和 `ecommerce-video-*.css` 用于保持原型的页面结构与视觉。
- 商品获取、发布中心保留原型交互，使用独立的浏览器演示数据；不访问 Demo 业务 API，也不执行真实抓取、上传或发布。
- 随附图片仅用于原型演示，不能作为实际商品素材或视频生成输入。
- 真实素材、文案、配音、记录接入在上级 `app.ts` 与 `prototype-views.ts`；选材与合成 UI 尚未接入原队列。
- 原型本机源目录保持不变。复制的脚本仅将示意图片路径调整到本目录，避免依赖原项目位置。

上游仓库：https://github.com/Lingentic/pm
