# 电商视频工作台 Demo

独立本地网页 + TypeScript 服务，采用原型的五模块布局。素材中心、文案／配音、AI选片、本地成片合成和生成记录已接入真实服务；商品获取接本机采集服务，发布中心是独立演示。

保存有效选片后点击“生成视频”，按真实音频时间拼接商品素材、蓝色固定画面及主播分屏图片，输出1080×1920／30 FPS／MP4。可开关黄字黑边字幕，选择／试听BGM并调音量。停止或失败后可重试本地合成，保留文案／配音／选片；设置重合成不重新调用模型、不重新选片。生成成功后可预览、返回编辑、确认完成或导出副本；确认完成后只读并后台清理中间文件。

配音完成后，在视频生成页点击“AI匹配素材”，使用阿里云 `deepseek-v4.1-flash` 一次选择所有商品画面空位。模型只读取当前商品候选视频的描述、ID和时长；固定主播与蓝色绑定保持锁定，蓝色不足部分也填商品视频。可手动调整并保存，时长不足提示未保存；失败保留旧方案、不会自动重试。接口已接通，付费可用性须以当前账户真实调用为准。

确认文案后显示“正在配音”，完成后自动进入视频生成页；失败仅由用户手动重试缺失区间。固定口播缩略图使用紫色锁定标识；视频生成页不再提供连续口播试听或本地配音导入区域。

主播原声片段下半屏改用本任务共用的商品图片。点击“调整图片”可在独立窗口拖动、缩放、还原或换图，实时查看渐变；应用后保存并统一用于所有主播原声片段。缺商品图时自动从商品视频截图。当前已接入预览、保存与实际成片合成。

点击生成视频前的工作保存为制作草稿，切走模块或刷新后返回视频制作会恢复原任务和步骤；仅保留最近一份草稿入口，不展示已有任务板块或历史草稿列表。首次受理视频合成后才进入生成记录，停止、失败与重试更新原记录。当前视频生成 UI 已接新逐空位合成，不开放旧随机队列入口。

Agent 修改代码从 [仓库入口](../AGENTS.md) 和 [按任务导航](../AGENT_WIKI.md) 开始；当前产品契约、架构与数据边界见导航中的专题，不把历史实验脚本当成常规测试。

商品原视频先进入素材中心的“原始视频”；选择当前商品后可勾选／全选并“切分并命名”。默认参数为 15.2／1.9 秒，成功后显示短名称和可展开的画面描述。配置、单次请求与恢复说明见 [素材处理](../docs/harness/MATERIAL_PROCESSING.md)。

## 启动

当前主要在 Windows 上验证，需要：

- Node.js 24。
- PATH 中可执行的 FFmpeg、FFprobe；FFmpeg 支持 `libx264` 编码和 ASS 字幕，中文字体使用微软雅黑。
- 生成文案／配音时使用的阿里云账户配置，以及对应的本地媒体素材。

没有 npm 生产依赖，不需要 `npm install`。在 `demo` 目录执行：

```powershell
node server.ts
```

打开 [http://127.0.0.1:4186/](http://127.0.0.1:4186/)。Windows 也可双击 [启动Demo.cmd](启动Demo.cmd)。服务只监听本机地址；这是需要本机启动的应用。

## 模型配置

文案与配音使用阿里云官方渠道：

| 用途 | 配置 |
| --- | --- |
| 补全文案 | `qwen3.7-plus`，按模板节点生成待填写内容，固定台词和模板顺序不改。 |
| AI 配音 | `qwen-audio-3.1-tts-plus`，小帅复刻音色、高昂版指令、1.1 倍语速；返回字级时间，再在本地聚合为字幕句子时间。 |
| 商品视频选片 | `deepseek-v4.1-flash`，一次安排全片空位，只发送候选描述、ID、时长和文案／配音时间。 |

在同一个 PowerShell 窗口设置自己的密钥后启动：

```powershell
$env:DASHSCOPE_API_KEY = '<你的阿里云 API Key>'
node server.ts
```

也支持 `BAILIAN_API_KEY`。本机开发可沿用已有客户端的环境文件，或在 `.local/settings.json` 中用 `credentialsFile` 指向包含上述变量的本地文件。密钥仅由服务端读取，不进入网页或参数快照。

配音参数位于 [data/voice-config.json](data/voice-config.json)，文案提示词位于 [data/copy-prompt.txt](data/copy-prompt.txt)。默认复刻音色需要账户有权使用；更换账户时应配置该账户可用的音色。配置存在不代表模型与音色权益已经验证。

文案、配音与选片只在用户明确提交对应操作后调用，失败或超时不会自动重发。确认文案会自动开始配音。

## 固定口播画面

已核对的固定口播画面由 [绑定清单](data/fixed-narration-visuals.json) 指定；视频不入 Git。先将对应文件放进同一文件夹，再在仓库根目录执行：

```powershell
node demo/scripts/import-fixed-narration.ts "<固定口播画面文件夹绝对路径>" "<当前数据根目录绝对路径>"
```

导入只复制并核对哈希，不修改外部原文件，不调用模型；同版本重复执行不新增资源。画面从指定节点开头／结尾播放，长口播的其余部分及未绑定节点由商品视频补齐。固定绑定不能被重新匹配或手动选材替换。

## 素材准备

仓库包含模板、提示词、演示商品文字、少量原型示意图片及三首默认配乐，不包含用户视频、用户配音或成片。原片预览需要本地素材，不能仅靠克隆仓库获得这些媒体。原型图片不进入实际素材库或生成流程。

原有鞋垫、拉链素材位于运行电脑桌面的 `mvp用` 目录时，空素材库会显示“导入示例素材”。目录结构为：

```text
桌面/mvp用/
├─ 鞋垫素材/鞋垫素材/
│  ├─ 产品素材/
│  └─ 老葛素材/
│     └─ 5s/
└─ 拉链素材/拉链素材/
   ├─ 产品素材/
   └─ 老葛素材/
      └─ 5s/
```

主播原片的示例文件名见 [lib/library.ts](lib/library.ts) 中的 `seedLibrary`；已核对的蓝色固定口播需使用上方的独立导入命令。导入会复制到托管数据目录，不改变外部原文件，已导入内容不重复复制。

默认 BGM 为 Happy Dance、Bouncing、Earth，来源与 CC0 许可见 [配乐说明](data/bgm/README.md)。启动或切换数据目录时自动复制入库，同一绑定不重复导入，不改变任务当前选择，默认仍无音乐。字幕与配乐是段落预览上方的独立设置卡，可试听和调整音量。

“导出副本”打开站内小窗口，默认当前电脑 Videos 目录，可填写或选择其他已存在目录；导出期间显示等待，失败可重试，成功显示完整路径。导出不改变任务状态，也不覆盖数据目录中的正式成片。

素材库也可添加商品资料，并为已有商品导入已处理片段或原始视频。手工已处理的片段直接入库；原始视频进入本地切分。上游提交商品 ID、名称、价格、规格、卖点与本地文件的契约见 [API.md](API.md)。

## 使用流程

1. **素材库**：沿用原型的 IP／产品分类和目录布局。产品目录按名称或 ID 搜索整个商品库，选择目录后显示该商品的素材；右侧另有当前目录的文件搜索。素材按全部／视频切片／原始视频／图片／声音筛选，原始视频页提供勾选处理，可预览、删除或仅重试失败文件。
2. **架构模版与文案**：在三步导航选择两个固定模板之一，文案页选择商品时建立任务。价格、规格只读，最终变量和待填文案可修改；固定节点不可改。可选范例供生成参考。
3. **自动配音**：点击“确认文案并生成配音”，以主播原片为分隔生成连续口播。页面展示进度，全部成功后自动进入视频生成页，提供音频试听；不再单独确认配音。失败可手动重试，仅补未就绪区间；改文案只重做受影响区间。
4. **视频生成页**：可提前浏览；配音就绪后显式AI匹配素材，按商品补位区间保存选择、手动增删及排序，固定口播锁定，蓝色画面不足由商品视频补齐。主播下半屏使用可调整的共用商品图。有效方案就绪后点击生成视频，支持字幕开关、BGM试听和音量；可停止或重试本地合成。成功后预览、返回编辑、确认完成或可选导出，发布保持未接入。
5. **生成记录**：沿用原型台账，读取本机任务；支持名称、商品 ID、任务 ID、状态和日期筛选，以及继续制作、折叠详情。既有成片可只读预览、导出，发布按钮暂不可用。首次受理视频合成后才显示记录；配音前后的草稿在制作页恢复，后续重试更新原记录。
6. **商品获取**：沿用采集界面，通过本机 Python 服务与 Chrome 扩展采集、导入商品及媒体；配置和一键启动见 [采集说明](../ecom-video-collect/README.md)。发布中心仍为独立演示，不执行发布。

模板在“架构模版”页切换，商品在“文案”页切换，直接使用页面中的下拉框。未提交视频且没有待填文案时直接覆盖草稿；已有文案时确认是否覆盖。只有已提交视频的可编辑任务才提供“保留并新建”，旧任务可从生成记录继续；取消保留原任务及进度。具体规则见 [当前产品契约](../docs/harness/PRODUCT.md)。

## 成片与数据

此前合成后端仍保留 **9:16、1080×1920、30 FPS、MP4**、上下分屏、字幕和 BGM 能力，但未连接当前新制作 UI；此轮没有更改旧成片或恢复其生成入口。

默认数据目录取当前运行电脑的 Windows“视频”已知文件夹（支持已重定向的位置），在其中建立 `电商视频工作台Demo`。不写死用户名。界面可更换目录；更换只是打开另一套数据，不自动搬迁旧素材。代码目录的 `.local/settings.json` 仅记本机目录及可选工具位置，不进入 Git。

SQLite 保存商品、素材和当前任务；任务保留文案、确认状态、音频、画面方案及输出参数。切换页面不停止后台合成；关闭服务后重启会恢复已保存结果，并标记中断，不自动提交付费重试。

确认完成后后台清理中间文件，保留成片、文案、参数快照及轻量时间记录。合成中可停止本地任务，已保存的文案、配音和选材可继续使用。

## 实现边界

- `.ts` 后端由 Node 24 直接执行；前端 TypeScript 在服务端擦除类型后提供给浏览器，没有另加打包框架或生产依赖。
- 新 UI 的逐空位选片和合成已接入，不复用旧随机商品队列；成功的选片保存于服务端。
- 当前演示素材按已处理视频导入。原始视频的镜头切分参数只是技术起点，未完成产品验收。
- 已定后续方向为入库时先裁首尾再切分；裁剪长度待定，暂未实现。原文件自带的极短片头、片尾仍可能出现在成片中。
- 主播原声段落下半屏使用保存的商品JPEG，其他画面使用视频；不拿缩略图随机补成片。
- 商品获取接现有本机采集服务；不实现真实发布、审核入库或多人共享。

## 验证与开发入口

已有离线行为与 FFmpeg 回归检查可在 `demo` 目录运行：

```powershell
node --test tests/workflow.test.ts tests/video-rendering.test.ts tests/preview-rework.test.ts
```

现有 10 项回归测试不调用付费模型。按本次改动选择对应文件；只改文档无需运行媒体合成。自动配音用例覆盖成功区间保留、失败重试、自动确认及不建立旧队列。历史验收不等于新 UI 的完整成片验证。
