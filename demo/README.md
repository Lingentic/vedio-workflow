# 电商视频工作台 Demo

三个模块：素材库、视频制作、生成记录。界面参考独立原型，业务规则沿用最简版。独立本地网页 + TypeScript 服务，不修改原型或旧客户端。

## 运行

需要 Node.js 24 和 PATH 中的 FFmpeg、FFprobe；没有 npm 生产依赖，不需要 npm install。

```powershell
node server.ts
```

打开 http://127.0.0.1:4186/。Windows 也可双击 `启动Demo.cmd`。

默认数据目录取当前运行电脑的 Windows“视频”已知文件夹（支持已重定向的位置），在其中建立 `电商视频工作台Demo`。不写死用户名。界面可更换目录；更换只是打开另一套数据，不自动搬迁旧素材。代码目录的 `.local/settings.json` 仅记本机目录及可选工具位置，不进入 Git。

模型使用官方 `qwen3.7-plus`、`qwen-audio-3.1-tts-plus` 及已确认小帅音色/1.1倍语速。密钥仅服务端读取环境变量 `DASHSCOPE_API_KEY`/`BAILIAN_API_KEY`；本机开发也可沿用已有客户端的本地环境文件，其他电脑可在 `.local/settings.json` 中设置 `credentialsFile`。密钥不进入网页、源文件、参数快照或 Git。配置存在不代表账号、地域和模型权益已验证。

当前用户已提供的素材放在桌面的 `mvp用` 目录时，素材库可点击“导入演示商品”，导入鞋垫、拉链商品和对应固定画面。媒体复制到托管数据目录，保留外部原文件。演示数据中的商品资料来自之前确认的测试样例；鞋垫使用本地演示ID `thermal-insoles`，拉链ID来自提供的SKU文本。

## 实现边界

- `.ts` 后端由 Node 24 直接运行；前端 `public/app.ts` 用 Node 自带 TypeScript 类型擦除后提供给浏览器，没有另加打包框架。
- SQLite 保存当前草稿与任务状态；FFmpeg 输出1080×1920、30 FPS、MP4，商品静音、红色原声、黄色字幕和可选独立 BGM。
- AI文案/配音只由用户按钮主动调用，失败或超时不自动重试。文案和音频分开确认，返工按连续口播区间复用有效结果。
- 当前演示素材按已处理视频导入。另行导入原始视频时支持本地镜头变化切分；默认检测参数是技术起点，不代表切分参数已经产品验收。
- 后续入库预处理方向：先统一裁掉首尾的一部分，再切分；裁剪长度待定，暂未实现。原视频自带的极短宣传片头、残留片尾留在该流程处理，不按个别文件写特例。当前合成仅使用视频流，JPG 缩略图仅供素材库展示。
- 生成成功进入预览，确认完成才只读。导出为可选副本，完成后后台清理本任务中间文件。
- 本机网页服务独立于浏览器标签页；切换模块或隐藏网页不会中断 FFmpeg。关闭服务进程后重启，恢复已保存结果并显示中断状态，不自动重发付费请求。
- 与上游及制作读取的接口见 [API.md](API.md)。不实现商品抓取、发布中心、审核入库或任意时间线编辑。

已完成的真实模型调用、页面操作及本地行为检查见 [验证说明.md](验证说明.md)。详细记录另存于被忽略的 `verification/`；旧实验音频不伪装成本次新调用。
