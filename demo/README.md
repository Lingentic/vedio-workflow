# 电商视频工作台 Demo

独立本地网页 + TypeScript 服务，提供素材库、视频制作、生成记录三个模块。支持从商品素材、模板文案、AI 配音一路生成可预览和导出的电商视频。

Agent 修改代码从 [仓库入口](../AGENTS.md) 和 [按任务导航](../AGENT_WIKI.md) 开始；当前产品契约、架构与数据边界见导航中的专题，不把历史实验脚本当成常规测试。

## 启动

当前主要在 Windows 上验证，需要：

- Node.js 24。
- PATH 中可执行的 FFmpeg、FFprobe；FFmpeg 支持 `libx264` 编码和 ASS 字幕，中文字体使用微软雅黑。
- 生成文案／配音时使用的阿里云账户配置，以及对应的本地媒体素材。

没有 npm 生产依赖，不需要 `npm install`。在 `demo` 目录执行：

```powershell
node server.ts
```

打开 [http://127.0.0.1:4186/](http://127.0.0.1:4186/)。Windows 也可双击 [启动Demo.cmd](启动Demo.cmd)。服务只监听本机地址；这是需要本机启动的应用。

## 模型配置

当前使用阿里云官方渠道：

| 用途 | 配置 |
| --- | --- |
| 补全文案 | `qwen3.7-plus`，按模板节点生成待填写内容，固定台词和模板顺序不改。 |
| AI 配音 | `qwen-audio-3.1-tts-plus`，小帅复刻音色、高昂版指令、1.1 倍语速；返回字级时间，再在本地聚合为字幕句子时间。 |

在同一个 PowerShell 窗口设置自己的密钥后启动：

```powershell
$env:DASHSCOPE_API_KEY = '<你的阿里云 API Key>'
node server.ts
```

也支持 `BAILIAN_API_KEY`。本机开发可沿用已有客户端的环境文件，或在 `.local/settings.json` 中用 `credentialsFile` 指向包含上述变量的本地文件。密钥仅由服务端读取，不进入网页或参数快照。

配音参数位于 [data/voice-config.json](data/voice-config.json)，文案提示词位于 [data/copy-prompt.txt](data/copy-prompt.txt)。默认复刻音色需要账户有权使用；更换账户时应配置该账户可用的音色。配置存在不代表模型与音色权益已经验证。

文案与配音只在用户点击对应按钮后调用，失败或超时不会自动重发。

## 素材准备

仓库只包含模板、提示词与演示商品文字资料，不包含视频、BGM、配音文件或成片。全流程需要模板对应的主播原片和通用主播画面，不能仅靠克隆仓库获得这些媒体。

原有鞋垫、拉链素材位于运行电脑桌面的 `mvp用` 目录时，可点击素材库的“导入示例素材”。目录结构为：

```text
桌面/mvp用/
├─ 鞋垫素材/鞋垫素材/
│  ├─ 产品素材/
│  └─ 老葛素材/
│     └─ 5s/
└─ 拉链素材/拉链素材/
   ├─ 产品素材/
   └─ 老葛素材/
      └─ 5s/
```

固定片段与文件名的对应关系见 [lib/library.ts](lib/library.ts) 中的 `seedLibrary`。导入会复制到托管数据目录，不改变外部原文件，已导入内容不重复复制。BGM 候选来自本机已入库音轨，仓库不内置音乐。

素材库也可添加商品资料，并为已有商品导入已处理片段或原始视频。手工已处理的片段直接入库；原始视频进入本地切分。上游提交商品 ID、名称、价格、规格、卖点与本地文件的契约见 [API.md](API.md)。

## 使用流程

1. **素材库**：打开“按商品查看”下拉框，按名称或 ID 搜索整个商品库，选中后显示该商品的完整素材列表；支持“全部商品”。素材按已处理、未处理与异常分组，可预览、删除或仅重试失败文件。
2. **文案**：开始新制作或继续已有任务。选择两个固定模板之一，价格和规格只供参考；用户可修改最终变量、填写可选范例，再生成全部待填写文案。确认前允许手动编辑。
3. **配音**：以主播原片为分隔，将相邻 AI 口播合为连续区间。逐区间试听、重配并确认；已确认时返回此页，可点击“画面设置 →”继续，保留配音和已有素材顺序。改文案只使受影响的区间失效，重配后重算相关时间。
4. **画面**：同商品视频随机组成全片连续队列，用完再重复并提示；通用主播画面播放时暂停商品队列。自动方案可按完整片段增删、拖动排序，需保存且满足时长要求才能继续；素材缩略图和时间线均支持点击预览。
5. **成片**：设置字幕开关、BGM 和音量，生成预览。BGM 不够长时循环并在末尾裁断。修改导致预览过期时，弹窗说明原因；只改字幕或 BGM 时保留画面，另可主动选择重新随机填充。
6. **完成与记录**：预览满意后点击“确认完成”，参数变为只读。成片默认保存在本机数据目录，按需导出副本。生成记录支持按任务／商品关键词、状态、创建日期筛选，以及继续未完成任务。

制作中可切换商品或模板：先在两个下拉框中选择，再点击“应用”。没有待填文案时直接覆盖当前草稿；已有文案时，再选择保留当前任务并新建，或清空当前进度后覆盖。返回保留刚才的选择，关闭窗口不修改任务；具体规则见 [当前产品契约](../docs/harness/PRODUCT.md)。

## 成片与数据

固定输出 **9:16、1080×1920、30 FPS、MP4**，等比例裁满画面中心。商品视频静音；主播原片保留原声，上方主播、下方商品，接缝渐变；字幕为统一黄色黑描边。原片字幕尽量由画面布局遮住，不执行字幕擦除。

默认数据目录取当前运行电脑的 Windows“视频”已知文件夹（支持已重定向的位置），在其中建立 `电商视频工作台Demo`。不写死用户名。界面可更换目录；更换只是打开另一套数据，不自动搬迁旧素材。代码目录的 `.local/settings.json` 仅记本机目录及可选工具位置，不进入 Git。

SQLite 保存商品、素材和当前任务；任务保留文案、确认状态、音频、画面方案及输出参数。切换页面不停止后台合成；关闭服务后重启会恢复已保存结果，并标记中断，不自动提交付费重试。

确认完成后后台清理中间文件，保留成片、文案、参数快照及轻量时间记录。合成中可停止本地任务，已保存的文案、配音和选材可继续使用。

## 实现边界

- `.ts` 后端由 Node 24 直接执行；前端 TypeScript 在服务端擦除类型后提供给浏览器，没有另加打包框架或生产依赖。
- 画面目前按连续商品队列填充，不做文案与画面的语义精确匹配；不实现逐镜头自由裁剪。
- 当前演示素材按已处理视频导入。原始视频的镜头切分参数只是技术起点，未完成产品验收。
- 已定后续方向为入库时先裁首尾再切分；裁剪长度待定，暂未实现。原文件自带的极短片头、片尾仍可能出现在成片中。
- 合成只使用视频，JPG 缩略图仅用于界面预览，不用于填充成片。
- 不实现商品抓取、发布中心、审核入库或多人共享。

## 验证与开发入口

已有离线行为与 FFmpeg 回归检查可在 `demo` 目录运行：

```powershell
node --test tests/workflow.test.ts tests/video-rendering.test.ts tests/preview-rework.test.ts
```

现有 9 项回归测试不调用付费模型。按本次改动选择对应文件；只改文档无需运行媒体合成。依赖旧实验数据或真实业务任务的三个一次性验收脚本已移除，历史执行结果仍保留在验证说明中。

已完成的真实模型调用、页面操作及本地行为检查见 [验证说明.md](验证说明.md)。详细记录另存于被忽略的 `verification/`；旧实验音频不伪装成本次新调用。
